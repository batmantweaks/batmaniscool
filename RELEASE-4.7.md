# batmaniscool 4.7.0

## New tools

- Startup Manager lists current Windows startup registrations and opens Windows Startup Apps for changes.
- Driver Checker reads installed display-driver details without changing drivers.
- Network Test shows the active adapter, gateway, average Cloudflare ping, jitter, and packet loss.
- Custom Profiles save queued controls locally and load them back into review without applying Windows changes.

## Interface

- Added a cleaner Tools & Diagnostics workspace.
- Added Release Center with download and publishing guidance.

## Safety

Diagnostics are read-only. Tuning controls still require explicit **Apply Changes** before Windows is changed.
