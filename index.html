What it changes

Each control explains its scope before it is queued. When supported, the app captures the original setting so it can be restored.

Important

Support

Useful information to collect before reporting a problem.

Before you apply

Review the pending list, close games and apps affected by the setting, and create a restore point if you are changing advanced controls.

Undo a change

Open History & Undo and use Revert for a completed item. For queued items, use Reset before you apply.

Report a problem

Include the app version, Windows version, the exact control used, and the System Execution Log result. Never share passwords or private account data.

Privacy

Clear boundaries for what this desktop app does and does not do.

Local by design

Login names, preferences, pending items, and change history stay in the local app profile. This app has no analytics or cloud account service.

Account note

The app login is a local convenience feature, not a replacement for a Windows account password or full security boundary.

Network behavior

The current app does not send tuning data to a server. A future optional update checker would contact only the chosen release server after it is configured.
